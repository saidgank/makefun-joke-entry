One line about working beside an AI coding agent — the kind of fix only a demo can produce. `main.py` writes it to `/output/entry.txt` on every run, byte-identical.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `out/entry.txt`, one line, 1–280 characters.
